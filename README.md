# 📰 My Daily News - E-Newspaper Website

A simple static HTML newspaper webpage built for learning basic HTML concepts.

## 📁 Project Structure
```
project/
└── index.html
```

## 🚀 How to Run

1. Download or copy the `index.html` file
2. Open it in any web browser (Chrome, Firefox, Edge)
3. No server or installation required!

## 📌 Features

- **Breaking News** section with bold formatted text
- **Today's Highlight** with HTML text formatting:
  - Subscript (`H₂O`)
  - Superscript (`mc²`)
  - Small and big text
  - Strikethrough text
- **Weather Report** table with city and temperature data
- **Read More** section with an external hyperlink

## 🧠 HTML Concepts Covered

| Concept | Tags Used |
|---|---|
| Headings | `<h1>`, `<h2>` |
| Paragraphs | `<p>` |
| Bold Text | `<b>` |
| Subscript | `<sub>` |
| Superscript | `<sup>` |
| Small Text | `<small>` |
| Strikethrough | `<del>` |
| Table | `<table>`, `<tr>`, `<th>`, `<td>` |
| Hyperlink | `<a href>` |
| Sections | `<section>` |
| Styling | `<style>` (internal CSS) |

## 🛠️ Built With

- HTML5
- Internal CSS (no external libraries)

## 📚 Learning Outcome

By studying this project, you will understand:
- How to structure a webpage using semantic HTML
- How to apply basic text formatting
- How to create tables in HTML
- How to add hyperlinks
- How to use internal CSS for basic styling
